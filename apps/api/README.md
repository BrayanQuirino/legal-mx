# API (planeada)

Futuro servicio NestJS con autenticación, búsqueda de profesionales, agenda y asistente basado en RAG. No desplegado ni operativo.

## Reglas
- Validar y sanitizar entradas.
- Autorización por rol: usuario, abogado verificado, editor jurídico y administrador.
- Cifrado y retención mínima para datos sensibles.
- Consultas de IA exclusivamente desde servidor; nunca exponer claves API en navegador.
