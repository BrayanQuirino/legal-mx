# Registro de fuentes jurídicas

No confundir un enlace a legislación con una versión vigente verificada. Toda incorporación debe registrar fuente oficial, jurisdicción, fecha de verificación, fecha de vigencia y, cuando corresponda, reformas y artículos específicos.

Fuentes candidatas para verificación editorial: portales oficiales del Congreso de la Ciudad de México, Consejería Jurídica CDMX, Legislación del Estado de México, Cámara de Diputados y Diario Oficial de la Federación.

No usar textos sin control de versiones para respuestas jurídicas. Ningún contenido de esta carpeta está listo para RAG todavía.
