# ADR-0001 — MVP estático antes del backend

Estado: Aceptado provisionalmente.

Motivo: Validar UX de descubrimiento antes de invertir en identidad, pagos, IA o agenda.

Decisión: React + TypeScript + Vite para MVP estático, con contratos de dominio desacoplados y evolución prevista a NestJS/PostgreSQL.

Limitaciones: Filtros actuales solo sobre especialidades; no existen profesionales ni reservas reales. El asistente no está conectado.
